# 户型成片 QA 清单

本清单用于验收 project.json → 成片的质量。每项检查应在渲染后通过人工或自动脚本完成。

## 几何校验（抽取 project.json 后）

- [ ] **墙体闭合**：所有外墙首尾相连，无断开
- [ ] **无自交**：墙体多边形无自相交
- [ ] **面积合理**：每个房间 area_m2 与几何计算面积误差 < 5%
- [ ] **房间数量**：rooms 数组包含所有 CAD 可识别房间
- [ ] **家具归属**：每个 furniture.room 对应一个存在的 room.id

## 渲染校验（成片抽帧后）

### 01 识别 READ
- [ ] 纸面清晰可读，无失真
- [ ] 扫描线动画完整
- [ ] 房间标签正确显示
- [ ] 面积明细表数值与 project.json 一致

### 02 图纸 DRAFT
- [ ] CAD 线条蓝色发光效果正确
- [ ] 四张图纸（平面/立面/剖面/家具）分离动画正常
- [ ] 尺寸标注正确

### 03 建模 BUILD
- [ ] **只有真正的墙从线里长出来**（无柜体/家具挤出）
- [ ] 门窗开口位置正确
- [ ] 家具按房间依次 pop-in
- [ ] 每个房间标签带正确的名字和面积

### 04 漫游 TOUR
- [ ] 每张 VR 图片正确显示
- [ ] Ken Burns 推镜流畅
- [ ] 房间切换时标签更新
- [ ] 无图片加载失败

### 05 日照 SUNLIGHT
- [ ] 太阳轨迹动画正确
- [ ] 热力图只在室内地面显示
- [ ] 时间显示正确推进
- [ ] 夜晚灯光逐间亮起
- [ ] 窗户发光

## 输出格式

- [ ] 分辨率：1280x720
- [ ] 帧率：30fps
- [ ] 时长：50-60秒
- [ ] 编码：H.264 + AAC
- [ ] contact.jpg 生成正确

## 修改建议输出格式

当发现问题时，按以下格式输出修改建议：

```json
{
  "field": "walls[3].openings[0].end",
  "current": 1.2,
  "suggested": 1.8,
  "reason": "门宽不足，应为 0.9m"
}
```
