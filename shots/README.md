# 镜头模块说明

本目录描述成片的固定镜头段落结构。所有镜头代码已冻结在 `render/web/` 中，只接受 project.json 参数。

## 镜头表

| # | 名称 | 时长 | 文件 | 描述 |
|---|------|------|------|------|
| 01 | 终端 | 1.5s | s1_terminal.js | Claude Code 窗口，打字效果 |
| 02 | 识别 | 7s | s2_scan.js | 户型图纸面扫描，AR 效果，房间识别 |
| 03 | 图纸 | 5s | s3_cad.js | CAD 蓝图，四张图纸分离 |
| 04 | 建模 | 7s | s_house.js (build) | 墙体生长，家具落位 |
| 05 | 漫游 | ~20s | s_vr.js | VR 图片 Ken Burns，拉回模型 |
| 06 | 日照 | 8.5s | s_house.js (sun) | 日照模拟，热力图，夜景 |

总时长约 50-55 秒。

## 段落结构

### 01 终端 TERMINAL
- 黑底 + 毛玻璃终端窗口
- 逐字打出 prompt
- 光标闪烁
- 推镜进入下一段

可配置：
- `shots.terminal.prompt`: 打字内容

### 02 识别 READ
- 暖光木桌上的户型图纸
- AR 扫描框 + 扫描线
- 墙体高亮
- 透视校正
- 房间标签 pop-in
- 面积明细表

数据来源：
- 纸面：自动从 project.json 生成
- 尺寸链：`geometry.dims_*`
- 房间：`rooms[]`
- 面积表：`area_table`

### 03 图纸 DRAFT
- 蓝色 CAD 线
- 平面图、南立面、剖面、家具布置
- 四张图纸分离成楼梯
- 慢速环绕
- 收回堆叠

数据来源：
- 墙体：`walls[]`
- 尺寸：`geometry.dims_*`
- 家具轮廓：`furniture[]`

### 04 建模 BUILD
- 黑底线框
- 墙体从线中挤出
- 闪白过渡到 studio 光
- 家具按房间依次 pop-in
- 房间标签带面积
- 慢速环绕

数据来源：
- 墙体几何：`walls[]`
- 家具：`furniture[]`
- 房间标签：`rooms[].name_zh`, `rooms[].area_m2`

### 05 漫游 TOUR
- 按顺序展示 VR 图片
- Ken Burns 推/拉
- 房间切换时标签更新
- 进度条 + 房间计数
- 最后一张缩小，相机拉回模型

数据来源：
- 图片序列：`vr_images[]`
- 房间名/面积：`vr_images[].room`, `vr_images[].area_m2`

### 06 日照 SUNLIGHT
- 太阳轨迹动画
- 热力图显示日照时长
- 时间推进 06:00 → 18:56
- 黄昏过渡
- 夜晚灯光逐间亮起
- 窗户发光
- 淡出

数据来源：
- 朝向：`meta.orientation`
- 纬度：`meta.latitude`
- 房间几何：`rooms[].bounds`

## 过渡效果

| 过渡 | 类型 |
|------|------|
| 01→02 | 推镜进入纸面 |
| 02→03 | 快速淡出/淡入 |
| 03→04 | 俯视→等距过渡 |
| 04→05 | VR 图片渐显 |
| 05→06 | 图片缩小 + 相机拉回 |

## 字幕系统

字幕由 `captions[]` 数组控制：

```json
{
  "t0": 2.0,      // 开始时间
  "t1": 4.9,      // 结束时间
  "zh": "只给它一张户型图",
  "hl": "一张户型图",   // 高亮词（红色）
  "en": "One floor plan. That's all it gets."
}
```

字幕位置：底部居中，白色大字 + 小号英文副标题。
